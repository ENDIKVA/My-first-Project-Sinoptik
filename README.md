# 🌤️ Synoptik — Weather Forecast Application

Интерактивное веб-приложение для просмотра текущей погоды и прогноза на 7 дней в любой точке мира. Проект разработан с акцентом на современный асинхронный JavaScript (ES6+), чистый код без сторонних тяжелых библиотек и адаптивный пользовательский интерфейс.

---

## 🚀 Основные возможности

* **Поиск городов с автодополнением:** Живой поиск через Geocoding API с дебаунсом для оптимизации запросов.
* **Подробный прогноз на 7 дней:** Отображение мин/макс температуры, вероятности и количества осадков.
* **Почасовая детализация:** Просмотр температуры и осадков по часам для каждого выбранного дня.
* **Интерактивные виджеты:** Анимированные круговые диаграммы (SVG Progress Rings) для отображения влажности воздуха и скорости ветра.
* **Автосохранение:** Сохранение последнего выбранного города в `localStorage` для мгновенной загрузки при повторном визите.
* **Индикатор загрузки (Spinner):** Плавная обратная связь для пользователя во время ожидания ответов от API.
* **Кроссплатформенность и адаптивность:** Полноценная поддержка ПК, планшетов и мобильных устройств на чистом CSS (Media Queries).

---

## 🛠️ Технологический стек

* **JavaScript (ES6 Modules):** `async / await`, Promises, Fetch API, DOM Manipulation, LocalStorage, Event Loop.
* **HTML5 & CSS3:** Flexbox, Grid, CSS Variables, Media Queries (`@media`), SVG animations.
* **External APIs:**
  * [Open-Meteo Geocoding API](https://open-meteo.com/en/docs/geocoding-api) — автодополнение и геокодинг городов.
  * [Open-Meteo Forecast API](https://open-meteo.com/en/docs) — точный прогноз погоды без использования API-ключей.

## 📂 Архитектура проекта

Проект построен по модульному принципу:

~~~text
├── main.html                 # Основная разметка приложения
├── styles.css                # Стили, адаптивная верстка и анимации
├── main.js                   # Точка входа и инициализация приложения

├── weatherDisplay.js         # Модуль получения и визуализации данных погоды
├── 7days.js                  # Логика обработки 7-дневного прогноза

└── placeholder.js            # Вспомогательные компоненты и плейсхолдеры
